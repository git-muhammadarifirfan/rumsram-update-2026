# Yayasan Rumsram - React + Tailwind

Project ini dibuat dengan:
- React + TypeScript
- Vite
- Tailwind CSS
- React Router DOM
- Framer Motion
- Lucide React

## Menjalankan project

### Dengan pnpm
```bash
pnpm install
pnpm dev
```

### Dengan npm
```bash
npm install
npm run dev
```

## Struktur utama
- `src/pages/HomePage.tsx` -> halaman beranda
- `src/pages/PlaceholderPage.tsx` -> template kosong untuk halaman lain
- `src/components/layout/SiteNavbar.tsx` -> navbar utama
- `src/ui/resizable-navbar.tsx` -> komponen navbar pendukung

Semua halaman selain home sudah disiapkan sebagai template kosong supaya nanti mudah kamu isi sendiri.
